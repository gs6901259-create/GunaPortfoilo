An interactive, dark-themed personal portfolio showcasing full-stack engineering, mobile apps, and AI projects. Built with React, Tailwind CSS, Framer Motion, and featuring a custom **interactive anime character rig** that naturally tracks cursor movements, blinks, and smiles.

---

## 🌟 Key Features

- **Interactive Anime Character Rig:**
  - 👁️ **Natural Eye Tracking:** Character irises smoothly follow cursor movements across the viewport without distortion.
  - 😊 **Living Facial Expressions:** Periodic natural blinking cycle and automatic gentle smile transitions.
  - 🎭 **Transparent Cutout:** Borderless, transparent character blending into the electric blue mesh gradient.

- **Featured Projects:**
  - **[SharePinz](https://sharepinz.online/):** Secure PIN-based peer-to-peer file sharing platform.
  - **Jama AI:** Upcoming AI calculator and voice assistant with step-by-step mathematical reasoning.

- **Design & UI:**
  - Floating animations and scroll-driven entry transitions with Framer Motion.
  - Multi-layered frosted glassmorphism (`backdrop-filter`) with specular top borders.
  - Responsive, high-contrast dark aesthetic with electric cyan and neon blue accents.

- **Direct Communication:**
  - Integrated contact form delivering messages directly to Gmail inbox (`varikuntagunasekhar@gmail.com`).
  - Interactive social links with hover glow effects (GitHub, LinkedIn, Instagram, Email).

## 💻 Local Development Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gs6901259-create/GunaPortfoilo.git
   cd GunaPortfoilo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
